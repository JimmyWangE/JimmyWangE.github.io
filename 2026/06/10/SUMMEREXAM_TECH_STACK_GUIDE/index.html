2. AndroidX ViewModel + LiveData

技术介绍

ViewModel 用来保存页面相关的数据，它的生命周期比普通 View 更适合承载页面状态。LiveData 是一种可观察数据容器，数据变化时，观察者会收到回调。

在 Android 里，ViewModel + LiveData 通常用来解决两个问题：

  • 页面数据不直接塞在 Activity / Fragment 里，减少 UI 层复杂度。
  • 数据变化自动通知界面刷新，不需要到处手动传回调。

LiveData 还有一个关键点：它能感知生命周期。页面销毁后，绑定到生命周期的观察者不会继续更新 UI。

7. Disposable + 生命周期回收

技术介绍

Disposable 可以理解成 RxJava 订阅的“取消开关”。调用 subscribe() 后会返回一个 Disposable。如果页面销毁了，但订阅还没取消，异步结果可能继续回调旧页面，造成内存泄漏或崩溃。

所以 Android 中使用 RxJava 时，通常要在页面销毁时统一取消订阅。

10. RecyclerView + Adapter + ViewHolder

技术介绍

RecyclerView 用来展示长列表。它的核心概念是复用：屏幕外的 item View 不会一直保留，而是被拿来显示新的数据。

一个 RecyclerView 通常需要：

  • LayoutManager：决定列表是纵向、横向、网格等。
  • Adapter：把数据转换成 item View。
  • ViewHolder：缓存 item 中的控件引用。

28. 建议学习顺序

如果你想按这个项目继续学，不建议一上来就看所有页面。推荐顺序：

  1. 先看 FirstTextFragment -> FirstTextViewModel -> FirstRepository -> FirstTextService，理解首页列表完整数据流。
  2. 再看 ApiGenerator -> MyInterceptor -> ApiWrapper -> Rxjava.kt，理解网络请求为什么能统一处理。
  3. 再看 FirstTextRvAdapter，理解 RecyclerView、多类型 item、ListAdapter、DiffUtil。
  4. 再看 LoginViewModel -> LoginService -> SharedPreferences -> MyInterceptor，理解 token 保存和自动携带。
  5. 再看 FindingFragment -> TiktokVpAdapter -> PrepareView，理解视频播放和 ViewPager2 视频流。
  6. 最后看 CommentBottomFragment、UserinfoActivity、MineFragment 等业务页面，验证前面的技术如何复用。
