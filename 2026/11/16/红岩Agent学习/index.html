1.6 异常处理

网络请求会失败、文件可能不存在，异常处理是 Agent 开发的日常。

原则：只捕获你知道怎么处理的异常，不要写裸的 except: 把所有错误悄悄吞掉，否则出问题时无从排查。

1.7 模块、标准库与文件读写

一个 .py 文件就是一个模块，用 import 使用。下面几个标准库后面都会用到：

  • 文件读写始终显式写 encoding="utf-8"，否则 Windows 上容易乱码。
  • json.dumps 把 Python 对象转成 JSON 字符串，json.loads 反过来；中文要加 ensure_ascii=False。
  • 入口约定：文件末尾写 if __name__ == "__main__":，表示「直接运行本文件时才执行」，被别人 import 时不执行。

1.8 读懂报错

报错信息（Traceback）从最后一行往上读：最后一行是错误类型和原因，往上是调用链，找到最靠近你自己代码的那一行。

常见错误 含义 典型原因
SyntaxError 语法错误 少了冒号、括号没配对
IndentationError 缩进错误 空格和 Tab 混用
NameError 名字未定义 拼错变量名、忘记 import
TypeError 类型不对 字符串和数字相加
KeyError 字典没有这个键 用 d["x"] 而不是 d.get("x")
IndexError 下标越界 列表长度不够
ModuleNotFoundError 找不到库 没装，或没进虚拟环境
FileNotFoundError 找不到文件 路径写错、当前目录不对

第 2 章 类型提示（Type Hints）

类型提示是给变量、参数、返回值「标注期望类型」。注意：Python 运行时不会检查它，它的价值在于①编辑器能提示和报错，②代码自带文档，③后面的 Pydantic 和 FastAPI 正是读取这些标注来做数据校验。所以这一章学扎实，任务二会很顺。
